# 明确不做

本文件是维护边界，不是待办列表。目的：把「不做什么」写清楚，避免重复讨论，也避免把有限的维护精力花在冻结范围。

判断标准：不改变正确性、可用性、安全性与计费透明度的主题打磨，不在维护范围内。

## 一、明确不做（不要提 PR）

方向 | 理由（一句）
WebView 壳 / 内嵌 chat.deepseek.com 官方网页 | 与原生 BYOK 体验和隐私边界冲突，且官方网页随时改版，壳无法保证可用
账号代登录、绕过人机验证、借用或共享 Key | 违反官方条款，也破坏「用户自己付费、费用可核对」的前提
破解额度、刷赠金、调用非公开接口 | 合规与稳定性风险不可控；只使用公开 API
云同步 / 账号系统 / 自建中转后端 | 本地优先：会话与 Key 不出本机，也不托管用户数据
广告、内购、代收费用、在官方价格上加价 | 应用免费且只做 BYOK 直连；任何加价都违背成本透明
自动重试风暴、静默重发、后台保活刷请求 | 会产生用户看不见的重复计费
第三方统计 / 崩溃上报 / 遥测 SDK | 本机优先，不收集用户数据
iOS / 桌面端 / 平板专版 | 当前范围只有 Android 手机；跨平台是另一个项目
